# 護理師歷屆甄選試題智能學習系統 (Nurse Exam Study System)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/version-3.0.0-blue.svg)](https://github.com/etrnya/nurse-exam)
[![Domain](https://img.shields.io/badge/Domain-Healthcare--Nursing-green.svg)](#)

本專案是一個運行於瀏覽器端的純靜態單網頁應用程式 (SPA)，旨在為護理國考考生與歷屆甄選考生提供高效的考題演練、錯題歸檔、知識點標籤統計分析與 AI 輔助即時解題之學習工具。系統不依賴任何後端資料庫，數據完全儲存於本機瀏覽器 LocalStorage，確保學習隱私安全。

---

## ✨ 核心特色與功能

### 1. 雙資料來源與權重推薦
系統整合了兩大高信度之護理選擇題庫：
*   **考選部專門職業及技術人員高等考試護理師考試**：收錄近 5 年 (110~114 年) 歷屆真題。對齊「試題」、「答案」與官方發布之「更正答案」，確保標準答案的絕對準確性。預設權重為 `1.0`。
*   **臺南市政府衛生局護理人員歷屆甄選試題**：收錄 92~114 年全量歷屆甄選題目。預設權重為 `1.5`。在隨機組卷或錯題複習時，高權重題目將獲得優先呈現。

### 2. 選擇題即時互動與容錯作答
*   **即時正誤判斷**：點擊選項按鈕即刻判定答案。判定正確時以綠色高亮，判定錯誤時以紅色高亮，並鎖定選項防止重複點擊。
*   **多重答案支援**：精準支援如 `B,D` 等多重答案考題（只要作答符合其中一個選項即判定正確）。
*   **一律給分支援**：對於官方判定一律給分之考題（資料庫標記為 `*`），作答任何選項皆判定為正確，並顯示「一律給分」提示。

### 3. Bento Grid 統計分析儀表板
*   **學習進度環形進度條**：動態展示當前學科已作答題目數占總題數的百分比。
*   **去重答題數據**：清晰呈現該學科「答對題數」、「答錯題數」與「整體正確率」。
*   **錯題本動態過濾**：提供「僅複習錯題」快速切換開關。勾選後，可即時過濾出當前科目或特定標籤下先前回答錯誤的題目，幫助考生精準補強弱點。

### 4. 專業科目與考點標籤分類
考題結構化分為 6 大學科：
1.  `基礎醫學` (包括解剖學、生理學、病理學、藥理學、微生物學與免疫學)
2.  `基本護理學與護理行政` (包括護理原理、護理技術與護理行政)
3.  `內外科護理學`
4.  `產兒科護理學`
5.  `精神科與社區衛生護理學`
6.  `綜合護理與公共衛生`

點選學科後，左側面板會呈現去重計算後的「二級考點標籤」（如生理學、心血管系統、臨床照護要點等）與題量統計，點選特定標籤即可快速篩選考題進行專題演練。

### 5. Gemini AI 串流解題助手
*   **即時解題**：整合 Gemini API，點擊「呼叫 Gemini AI 即時解題」即可針對當前考題生成結構化 Markdown 解析。
*   **LocalStorage 快取**：生成解析後自動保存至本機快取，再次瀏覽該題時直接加載，不消耗 API 額度。
*   **提示詞複製**：提供一鍵複製提示詞範本功能，方便複製到外部 AI 進行深度探討。

## 🛠️ 技術架構與分層 (DDD 分層)

專案嚴格遵守領域驅動設計 (Domain-Driven Design) 分層規範，確保代碼高內聚低耦合：

*   **領域層 (Domain)**：定義於 [GLOSSARY.md](GLOSSARY.md)，規範核心資料模型欄位（如 `id`、`question`、`options`、`answer`、`subject`、`tags`、`weight`）與業務邊界。
*   **表現層 (Presentation)**：[study_portal.html](study_portal.html) 純靜態網頁，負責美觀的醫護綠色調 UI 呈現與動態作答反饋。
*   **應用層 (Application)**：封裝在 [study_portal.html](study_portal.html) 內部的狀態管理與事件邏輯，包含 LocalStorage 錯題歸檔、統計計算與 Gemini API 串流處理。
*   **基礎設施層 (Infrastructure)**：
    *   `download_moex_exams.py`：考選部歷屆試題 PDF 自動下載腳本。
    *   `download_tainan_exams.py`：臺南市衛生局甄試 PDF 自動下載腳本。
    *   `parse_exams.py`：PDF 文字提取、答案優先級比對與結合 LLM 自動化標籤分類腳本。
    *   `questions_db.js` / `answers_db.js`：提煉後的靜態結構化選擇題庫與答案庫。

## 🚀 本地使用與部署指南

### 本地瀏覽
本專案為純靜態網頁，無需安裝任何後端環境或伺服器。
1.  下載本專案原始碼。
2.  在瀏覽器中直接雙擊打開 `study_portal.html`，即可開始使用。

### 啟用 AI 解題功能
1.  開啟本機瀏覽的模擬測驗網頁。
2.  點選左下角的「設定 · API 金鑰 · 題庫管理」按鈕。
3.  在「Gemini API 金鑰」分頁中輸入設定之 API 金鑰，並選擇模型（預設為 `gemini-2.5-flash`）。
4.  點選「儲存至本機」即可完成設定（API 金鑰僅儲存於本機瀏覽器 localStorage，不會上傳至任何伺服器）。
